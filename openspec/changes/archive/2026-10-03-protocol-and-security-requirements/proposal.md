# Proposal: Requirements recorded for the protocol and security

> Retro archive entry, reconstructed on 2026-10-18 from git history, Basic Memory notes and itests/USE_CASES.md (branch `itests`). Spec deltas are not kept; the resulting behavior is in `openspec/specs/`.

## Why

The decision log of 2026-10-03 recorded requirements that were not implemented at the time, so that later work would keep to them (Basic Memory `main/projects/tilr/tilr-zhurnal-reshenii`).

## What Changes

- Extensible protocol: a typed envelope (later realised as protobuf `oneof` plus a `features` list, unknown messages ignored).
- End-to-end encryption required; details deliberately not fixed (open change `end-to-end-encryption`).
- Supervisor-to-pane over Unix sockets by default, TCP optional with mandatory authentication.
- A mandatory token on the signalling WebSocket, checked at the handshake, generated by the supervisor, sent in a header rather than the URL (realised as `Hello.token` on 2026-10-09).
- Default bind 127.0.0.1, recommended mode "localhost + cloudflared outbound tunnel" (realised by Cloud on 2026-10-09).
- Feature requests: PaneActivity notifications, TCP service forwarding (Postgres, Redis), remote browser/desktop over WebRTC (open changes `pane-activity-notifications`, `port-forwarding`).
